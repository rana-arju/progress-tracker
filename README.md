# রুটিন ট্র্যাকার

সাপ্তাহিক রুটিন মেনে চলার জন্য একটা ছোট ওয়েব অ্যাপ। English, AI Engineer প্রজেক্ট, ইন্টারভিউ প্রস্তুতি আর চাকরির আবেদন: প্রতিদিন কোনটা হলো, কোনটা বাদ গেল, আর সাপ্তাহিক, মাসিক ও সারাজীবনের অগ্রগতি দেখায়।

**Stack:** Vite · React 18 · TypeScript · Tailwind CSS v4 · localStorage (কোনো backend নেই)

## ফিচার

- **আজ:** এখন কোন কাজের সময় আর কত মিনিট বাকি, পরের কাজ, টিক দেওয়া, সময় পার হয়ে যাওয়া কাজ "বাদ পড়েছে" চিহ্নিত, আর প্রতিদিনের শেখার নোট
- **রিমাইন্ডার:** ট্যাব খোলা থাকলে প্রতিটা কাজ শুরুর সময় ব্রাউজার নোটিফিকেশন
- **সপ্তাহ:** শনি থেকে শুক্র, প্রতিদিনের হার, ধরন অনুযায়ী অগ্রগতি, সবচেয়ে বেশি বাদ পড়া কাজ
- **মাস:** ক্যালেন্ডার, প্রতিটা দিনের রং দেখে বোঝা যায় কতটা কাজ হয়েছে
- **সারাজীবন:** মোট হার, সফল দিন, streak, সব শেখার নোট
- **বাদ পড়া:** গত ৭/১৪/৩০/৯০ দিনে কবে কোন কাজ বাদ গেছে
- **লক্ষ্য:** সাপ্তাহিক লক্ষ্যের কাউন্টার আর আগের সপ্তাহগুলোর হিসাব
- **প্রতিদিন নতুন মোটিভেশন লাইন**
- **Backup:** JSON ফাইলে ডাউনলোড আর সেখান থেকে ফেরত আনা
- **ডার্ক মোড:** সিস্টেমের সেটিং অনুযায়ী নিজে থেকে

## লোকালে চালানো

```bash
npm install
npm run dev
```

তারপর `http://localhost:5173` খোলো।

## Vercel-এ deploy

**পদ্ধতি ১: GitHub দিয়ে (সুপারিশ)**

1. এই ফোল্ডারটা একটা নতুন GitHub repo-তে push করো
2. [vercel.com](https://vercel.com)-এ লগইন করে **Add New → Project** চাপো
3. repo-টা বেছে নাও। Vercel নিজেই বুঝবে এটা Vite প্রজেক্ট:
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. **Deploy** চাপো। এরপর প্রতিটা `git push`-এ নিজে থেকেই নতুন deploy হবে

**পদ্ধতি ২: CLI দিয়ে**

```bash
npm i -g vercel
vercel        # প্রথমবার প্রশ্নগুলোর উত্তর দাও
vercel --prod
```

## রুটিন বদলাতে

সব কাজ, সময়, ফোকাস টপিক আর সাপ্তাহিক লক্ষ্য একটা ফাইলেই আছে: `src/data/routine.ts`।

- সময় ২৪-ঘণ্টা ফরম্যাটে। রাত ১২টার পরের সময় ২৪-এর বেশি লেখো (রাত ১টা = `"25:00"`), কারণ সেটা আগের দিনের রুটিনের অংশ
- রাত ৪টার আগে পর্যন্ত আগের দিনের রুটিন চলছে বলে ধরা হয় (`DAY_ROLLOVER_HOUR`)
- `track: false` দিলে কাজটা দেখাবে, কিন্তু টিক বা হিসাবে আসবে না (যেমন বিশ্রাম)
- কোনো কাজের `id` বদলালে আগের দিনের সেই কাজের টিক আর মিলবে না। তাই পুরনো কাজের `id` বদলিও না
- ৮০% বা বেশি কাজ হলে দিনটা "সফল" ধরা হয় (`SUCCESS_THRESHOLD`)

মোটিভেশন লাইন বদলাতে বা যোগ করতে: `src/data/quotes.ts`।

## ডেটা কোথায় থাকে

সব ডেটা ব্রাউজারের `localStorage`-এ, `routine-tracker-v1` নামে। তাই:

- একটা ডিভাইস আর একটা ব্রাউজারেই ডেটা থাকবে, অন্য ফোন বা ল্যাপটপে দেখাবে না
- ব্রাউজারের history বা site data মুছলে ডেটাও মুছে যাবে, তাই প্রতি সপ্তাহে একবার **Backup ডাউনলোড** করে রাখো
- অন্য ডিভাইসে নিতে চাইলে backup ফাইলটা সেখানে **Backup থেকে ফেরাও** দিয়ে আপলোড করো

পরে সব ডিভাইসে sync চাইলে Supabase বা নিজের FastAPI backend যোগ করা যায়। `src/lib/storage.ts`-এর `load` আর `save` ফাংশন বদলালেই হবে।

## ফোল্ডার

```text
src/
├── data/routine.ts      # রুটিন, সময়, লক্ষ্য (এখানেই বদলাবে)
├── data/quotes.ts       # মোটিভেশন লাইন
├── lib/date.ts          # তারিখ, সময়, বাংলা সংখ্যা
├── lib/storage.ts       # localStorage, backup
├── lib/stats.ts         # শতাংশ, বাদ পড়া কাজ, streak
└── components/          # আজ, সপ্তাহ/মাস/সারাজীবন/বাদ পড়া, লক্ষ্য
```
